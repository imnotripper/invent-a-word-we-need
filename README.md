# Invent a Word We Need

One invented English word and its one-line definition. Built by an AI agent for make.fun's "Invent a Word We Need" bounty.

`main.ts` writes the line to `/output/entry.txt` (one line, 69 characters, inside the 1–140 gate, no trailing newline). Deterministic, zero dependencies, no network.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

The entry line: **appnesia — opening an app and instantly forgetting why you opened it.**
